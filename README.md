# derbytrade
Данные: база данных по торговле рыбными товарами ФАО.

Определения и ограничения:
В файле trade_ddl.sql ddl-структура базы данных apache derby embedded с описанием контента в комментариях.
В папке /CSV лежат .csv дампы таблиц этой базы данных, включая две основных таблицы данных TSD_TRADE_VALUE (стоимость) и TSD_TRADE_QUANTITY (вес), остальные таблицы либо описательные списки REF_ либо реляционные REL_
Поля, не описанные комментариями в DDL - не имеет никакого значения и игноируются.
В базе много полей с именованиями на языке отличном от английского - они игноруются, используются только поля _EN (английский язык).
SQL-запросы создаются в диалекте Apache Derby (обязательно), диалект Derby является крайне ограниченным по сравнению с современным SQL и при этом обязателен для доступа к базам derby, поэтому надо учитывать тонкости и ограничения диалекта.

Задача:
1) проанализировать структуру базы;
2) создать  SQL-запросы в диалекте derby;
3) сформировать python программу для получения Excel-файла (результата работы) где лист = таблица запросов.
4) ниже идет список таблиц, для формирования которых надо создать соответствующие SQL-запросы

Таблица 1. Основные страны-экспортеры (по стоимости, тыс.долларов)
колонки: №1 список стран, №2-№5 данные за последние 4 года
строки: заголовок, 30 стран-лидеров (по убыванию, уровню последнего года), сумма (всего за год), сумма 30 стран-лидеров, прочие страны (всего минус 30 стран-лидеров)

Таблица 2. Основные страны-экспортеры (по весу, тонн)
колонки: №1 список стран, №2-№5 данные за последние 4 года
строки: заголовок, 30 стран-лидеров (по убыванию, уровню последнего года), сумма (всего за год), сумма 30 стран-лидеров, прочие страны (всего минус 30 стран-лидеров)

Таблица 3. Основные страны-импортеры (по стоимости, тыс.долларов)
колонки: №1 список стран, №2-№5 данные за последние 4 года
строки: заголовок, 30 стран-лидеров (по убыванию, уровню последнего года), сумма (всего за год), сумма 30 стран-лидеров, прочие страны (всего минус 30 стран-лидеров)

Таблица 4. Основные страны-импортеры (по весу, тонн)
колонки: №1 список стран, №2-№5 данные за последние 4 года
строки: заголовок, 30 стран-лидеров (по убыванию, уровню последнего года), сумма (всего за год), сумма 30 стран-лидеров, прочие страны (всего минус 30 стран-лидеров)

Таблица 5. Товарная структура мировой торговли по 10 группам 
колонки: №1 товарные группы (10 основных групп товаров, FAO major group), №2 тип данные (количество "К", стоимость "С"), №3-№6 данные за последние 4 года по экспорту, №7-№10 данные за последние 4 года по импорту

Таблица 6. Товарная структура мировой торговли по странам

строки: заголовок, всего по 10 группам (итого, сумма), 10 групп суммарно (итого по каждой из 10 позиций), и данные по каждой стране - страна с итогом по стране 2 строки (количество "К", стоимость "С") + 10 групп по этой стране 2 строки на каждую из 10 позиций (количество "К", стоимость "С")
